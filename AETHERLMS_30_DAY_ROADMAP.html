1. Executive Summary & Competitive Moat

Online higher education platforms today fall into two distinct silos: Coursera excels in fluid video delivery and modular navigation, yet suffers from ~12% completion rates due to the absence of rigid milestones; NPTEL excels in academic rigor, weekly assignments, and proctored examinations, but is handicapped by dated user experiences and rigid non-adaptive scoring.

Coursera Limitations
  • × Soft deadlines permit indefinite procrastination
  • × Lacks automated Best-of-N score-drop calculation
  • × No scheduled proctored exam slot allocation
NPTEL Limitations
  • × Dated video streaming interface with no seek sync
  • × No real-time searchable transcript integration
  • × Slow, manual assignment review cycles
AetherLMS Synthesis
  • ✓ 0.5x–2.0x HLS streaming with interactive transcript seek
  • ✓ Hard cutoff weekly deadlines with Best 8 of 12 engine
  • ✓ Dynamic QR cryptographic certificate verification

3. Detailed Day-by-Day Engineering Plan

Week 1 • Foundation, Database Architecture & Role Security (Days 1–7)

Days 1–2: Relational PostgreSQL Schema & Row Level Security (RLS)
  • Deploy 16 relational tables with strict foreign keys and delete cascades across courses, modules, lessons, submissions, quizzes, certificates, and exams.
  • Write database-level helper functions: is_admin(), is_instructor(), and is_evaluator().
  • Apply strict Row-Level Security policies guaranteeing students can never access draft curriculums or peer submission archives.
Days 3–4: Next.js 14 App Router & Global Layout System
  • Initialize Next.js 14 with TypeScript, Tailwind CSS, and Shadcn UI component primitives.
  • Configure QueryClientProvider with 5-minute cache deduplication and react-hot-toast notifications.
  • Construct high-performance layout shells: Student Dashboard, Instructor Studio, and Admin Command Terminal.
Days 5–7: Supabase SSR Authentication & Edge Middleware Guards
  • Implement secure cookie-based session handling using @supabase/ssr.
  • Build Email/Password and OAuth (Google & GitHub) authentication workflows with Zod input validation.
  • Configure Next.js edge middleware (middleware.ts) enforcing instantaneous role-based routing.

Week 2 • Next-Gen Content Engine — Beyond Coursera (Days 8–14)

Days 8–10: Immersive Video Classroom & Synced Transcripts
  • Custom video player with playback speeds (0.5x, 0.75x, 1.0x, 1.25x, 1.5x, 2.0x), scrubber, and auto-advance.
  • Zustand usePlayerStore persisting user playback rate and volume settings to local storage.
  • Interactive, searchable transcript viewer: clicking any sentence cue jumps the video scrubber directly to that exact second.
  • Auto-save playback progress down to the second in lesson_progress.
Days 11–12: Instructor Curriculum Builder Studio
  • Drag-and-drop course builder supporting Weeks 1–12 with video, article, quiz, and lab lesson types.
  • Prerequisite locking toggle: enforce sequential completion before unlocking subsequent academic modules.
  • Supabase Storage integration with signed upload URLs for video MP4/HLS streams and code starter archives.
Days 13–14: Faceted Course Discovery & Instant Enrollment
  • Searchable catalog with real-time filters for Category, Difficulty, Rating, and Hours.
  • Public course syllabus detail page with 12-week breakdown and grading rubric disclosure.
  • One-click enrollment writing immediately to public.enrollments.

Week 3 • Rigorous Evaluation & Assignment Engine — NPTEL Evolution (Days 15–21)

Days 15–17: Anti-Cheat Timed Quiz & Rigid Assignment Module
  • Full-screen timed quiz engine with countdown clock and visual Question Jump Palette (Answered, Unanswered, Flagged).
  • Automated score calculation for Single & Multiple Choice questions with strict auto-submit on countdown expiry.
  • Assignment submission portal with live hard-cutoff countdown clocks (DD:HH:MM:SS).
  • Multi-mode submission: ZIP/PDF upload, embedded Go/Rust/C code editor, and SHA-256 submission receipt generation.
Days 18–19: The "Best of N" Flexible Score Engine
  • Implement PostgreSQL calculate_best_of_n_score trigger function.
  • Automatically drops the lowest 4 scores in a 12-week course and computes the arithmetic mean of the top 8 weeks.
  • Interactive student dashboard simulator highlighting counted vs. dropped scores and certificate eligibility.
Days 20–21: TA Gradebook Queue & Real-Time Discussion Boards
  • Evaluator grading queue with automated CI test-pass verification and rubric point sliders.
  • Module-scoped discussion forums powered by Supabase Realtime channels with "Instructor Answered" verification badges.

Week 4 • Verification, Gamification, QA & Production Launch (Days 22–30)

Days 22–23: Dynamic PDF Certificates & Public QR Verification
  • Automated certificate issuance trigger when composite grade satisfies the passing threshold (≥ 75%).
  • High-resolution diploma PDF generation with student honors, instructor signatures, and institutional crest.
  • Public verification route (/verify/[certificateId]) with cryptographic hash lookup and QR validation.
Days 24–25: Performance Hardening & Mobile Responsive Polish
  • B-Tree database indexing on high-frequency foreign keys (user_id, course_id, assignment_id).
  • Mobile viewport optimization with touch-friendly player gestures and responsive bottom navigation.
Days 26–27: Autonomous Playwright End-to-End Testing
  • Automate the complete Student journey: Register → Catalog → Video → Timed Quiz → Submit Lab → Receive Certificate.
  • Security penetration tests verifying zero RLS data leaks between unauthorized roles.
Days 28–30: Production Deployment & Go-Live
  • Deploy to Vercel edge network with SSL, custom domain, and Supavisor connection pooling.
  • Configure Sentry error tracking, automated daily database backups, and synthetic health monitoring.
